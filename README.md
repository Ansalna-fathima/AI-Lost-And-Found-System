AI-Powered Lost and Found System

Overview

An AI-powered multi-modal lost and found management system that combines Computer Vision and Natural Language Processing techniques for intelligent item matching and retrieval.

The system uses MobileNetV2 and Siamese Neural Networks for image similarity matching, along with BERT/Sentence Transformers for semantic text similarity analysis.

---

Key Features

- AI-based image recognition
- NLP-based text similarity matching
- Multi-modal item matching
- Real-time match prediction
- Flask-based web application
- SQLite database integration
- Intelligent recovery recommendations

System Workflow

1. User uploads lost/found item
2. Image features extracted using MobileNetV2
3. Text embeddings generated using BERT
4. Cosine similarity calculated
5. AI matching engine predicts possible matches
